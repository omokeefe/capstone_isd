# SysIDE Modelling Knowledge
This file will contain links and info relevant to best practices and fundamental methods associated with executing common SE concepts (e.g. context diagrams, state diagrams, establishing connections & ports, etc.).


[SYSIDE Diagram Views](https://docs.sensmetry.com/about/sysml-v2-diagram-coverage/#sysml-v2-diagram-coverage)
| View definition       | View kind                                           |
| --------------------- | --------------------------------------------------- |
| `GeneralView`         | General (structure, containment, and relationships) |
| `InterconnectionView` | Interconnection (parts wired through ports)         |
| `ActionFlowView`      | Action flow (actions and control flow)              |
| `StateTransitionView` | State transition (states and transitions)           |
| `SequenceView`        | Sequence (lifelines and messages)                   |
