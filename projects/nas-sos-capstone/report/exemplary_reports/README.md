# Exemplary Reports

Sample capstone reports for the technical-editor persona
(`personas/technical-editor.md`) to calibrate against — "what does a strong
ISD 503 report actually look like," beyond the template's own abstract guidance.

**This folder is currently empty.** Add prior years' strong 503 reports, an
advisor-recommended example, or anything else you'd want the editor persona to hold your
draft up against. PDFs or Word docs are both fine; no specific naming convention
required. The persona checks this folder each review pass and says so explicitly if it's
still empty rather than silently reviewing without that calibration.
