# Exemplary Reports

Sample capstone reports for the technical-editor persona
(`personas/technical-editor.md`) to calibrate against — "what does a strong
ISD 503 report actually look like," beyond the template's own abstract guidance.

Currently populated with sample final reports from six other ISD 503 project tracks
(AUTO503, DESCI503, ESENG503, GAME503, MFG503, SED503). Add more — prior years' strong
503 reports, an advisor-recommended example, or anything else you'd want the editor
persona to hold your draft up against — at any time; PDFs or Word docs are both fine, no
specific naming convention required. The persona checks this folder each review pass and
says so explicitly if it's empty rather than silently reviewing without that calibration.
