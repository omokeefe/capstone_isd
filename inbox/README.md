# Inbox

A quick-capture zone for small things that need to be written down before they're lost,
but don't yet warrant the full literature-processing pipeline — a web excerpt, a stray
idea, a half-formed observation, a quote from a conversation. Distinct from
`evidence/sources/` + `/process-references`, which is for independent, comprehensive
sources (a full paper: bib entry, rating, summary) — the wrong tool for a two-sentence
excerpt.

## How to use it

Drop a note in here in whatever form it arrives — pasted text plus a source link/date is
enough, no required template. Don't feel obligated to structure it before capturing it;
that's what triage is for.

## Triage

Per `workflows/process-inbox.md` (skill: `/process-inbox`): periodically (a good trigger
is a non-empty inbox at session-wrap-up time), go through what's here and decide, per
item, whether it becomes a real evidence note, a knowledge concept/claim, a decision
candidate, or project-specific to-do fodder — then move it to that home and update the
relevant index, or delete it if it turned out not to matter.

## What this folder does not depend on

Perfect, prompt processing. An item sitting here untriaged for a while is not a failure
state — per this workspace's maintenance philosophy, the point is that nothing gets lost
before it can be judged, not that everything gets filed immediately.
