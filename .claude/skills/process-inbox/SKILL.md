---
name: process-inbox
description: Triage the quick-capture inbox/ folder — sort each item into a knowledge, evidence, decision, or project home, or delete it if it didn't turn out to matter. Use when asked to process, clear, or check the inbox, or as a light check during session wrap-up if inbox/ is non-empty.
---

Follow `workflows/process-inbox.md` exactly. If `inbox/` is empty, say so and stop — this
isn't a required step every session. For each item, decide whether it's a literature
source in disguise (redirect to `/process-references`), a glossary term
(`knowledge/concepts/glossary.md`), a claim candidate (flag for the user per
`knowledge/claims/README.md` rather than drafting it yourself), a model detail
(`knowledge/models/`), a decision (`decisions/decisions-log.md`), an open question
(`knowledge/questions/open-questions.md`), project-specific fodder
(`projects/nas-sos-capstone/task-board.md` or `to-do-list.md`), or just not worth keeping.
Remove each item from `inbox/` once filed.
