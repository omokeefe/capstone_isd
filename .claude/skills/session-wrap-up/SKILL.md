description: Close out a capstone work session — write a session log, update the task board, sync memory files, and verify to-do-list.md checkboxes match reality. Use at the end of a session or when the user says they're done for now.
---

Follow `workflows/session-wrap-up.md` exactly: write a session log to
`projects/nas-sos-capstone/sessions/` from `templates/session-log-template.md`, update
`projects/nas-sos-capstone/task-board.md`, sync any stale memory/knowledge files that
changed (`projects/nas-sos-capstone/index.md`, `decisions/decisions-log.md`,
`knowledge/questions/open-questions.md`, `evidence/source-register.md` as applicable),
and confirm `projects/nas-sos-capstone/to-do-list.md` checkboxes reflect what was
actually completed.
