# Reference Summaries

One file per processed reference in `../../sources/`, generated by
[workflows/process-references.md](../../../workflows/process-references.md)
(skill: `/process-references`). Each summary describes what the source is, which part(s)
of the capstone it's valuable to, and a 0-5 relevance rating. The authoritative index of
what's been processed and when is
[evidence/source-register.md](../../source-register.md)'s
Processing Ledger — this folder holds the detail behind each ledger row.
