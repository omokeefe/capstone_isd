This file is an earlier conference-manuscript draft (SE-101006, received 9 Oct 2009) of
what was later published as `bartolomei2012esmdm` ("Engineering Systems Multiple-Domain
Matrix," *Systems Engineering* Vol. 15, No. 1, 2012). Same authors (Bartolomei, Hastings,
de Neufville, Rhodes), same MIT affiliation, nearly identical abstract — the draft's title
omits "Multiple-Domain" ("Engineering Systems Matrix: An Organizing Framework for Modeling
Large-Scale Complex Systems"). It was filed under "de Neufville" (the third author)
presumably because that's whose name was on the file, not because it's a distinct de
Neufville-authored work — worth knowing this isn't a separate de Neufville paper if it
gets searched for by that name later.

See [bartolomei2012esmdm.md](bartolomei2012esmdm.md) for the full summary of the published
version.
