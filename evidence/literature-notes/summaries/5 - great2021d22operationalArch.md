## What it is

A primary EU-China Horizon 2020 project deliverable (technical report). Directly builds on
`great2020d21tboConcept`'s TBO baseline and greener-ATM concept elements to derive a formal
operational and system architecture, using a stated MBSE methodology and architecture description
framework. Performs requirement analysis from the top-level TBO operational concept, establishes a
gate-to-gate set of ATM operation processes/phases, and builds separate operational-view and
system-view architecture models.

## Why it's valuable — and to what

- Literature review section: none / directly an architecture source, not background literature.
- Decomposition / architecture (§6, §10): this is the single most directly relevant new source in
  this batch for the capstone's core architecture work — an MBSE-derived, gate-to-gate operational
  and system architecture of the ATM system, explicitly traced back to a TBO operational concept.
  Provides a concrete precedent (method, framework, and worked example) for exactly the kind of
  operational-concept-to-architecture derivation this capstone's own decomposition work needs to
  perform.
- Stakeholder / objective ontology (§7-§9): operational-view models typically capture actor roles
  and activities across the gate-to-gate process, relevant to stakeholder/responsibility mapping.
- Optimization study (§11-§13): the gate-to-gate process structure is a candidate scaffold for
  scoping where optimization capabilities plug into the architecture.
- Glossary / terminology: "operational architecture" vs. "system architecture" distinction,
  gate-to-gate ATM process terminology.
