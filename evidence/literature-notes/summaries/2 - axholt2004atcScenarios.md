## What it is

A master's thesis / implementation project report, conducted at the EUROCONTROL Experimental
Centre (Brétigny-sur-Orge, France) under supervisor Vu Duong. Describes the design and
implementation of an application that lets a user create air-traffic datasets — manually or via
bulk import from external sources — and compile them into test scenarios, output as datasets for
a prototype ATC software system ("TRAMO") developed at Linköping University.
